# cctv.sopnotec.com

Static site for SopnoTec CCTV Monitoring (remote 24/7 CCTV monitoring for U.S. businesses).

- `index.html` — the full site with interactive Three.js 3D scenes
- `three.min.js` — Three.js r149 (MIT licence)
- `send.php` — lead-form handler that emails requests to abubakar@sopnotec.com
- `.htaccess` — default page, compression and caching

Deployed to Hostinger (cctv.sopnotec.com) from this `cctv-site` branch.
